
# MB5370 — Programming Fundamentals for Marine Science

This repository documents my practical programming exercises for MB5370 at James Cook University.

## Project Overview

The project demonstrates introductory R programming, marine science data visualisation, reproducible workflows, and version control using Git and GitHub.

## Workshop Progress

- **Workshop 1:** Introduction to R programming, data structures, and summary statistics.
- **Workshop 2:** Data visualisation using base R and ggplot2.
- **Workshop 3:** Version control using Git and GitHub.

## Project Structure

- `code/` — R scripts and programming exercises
- `docs/` — Quarto reports and HTML documents
- `output/` — Exported figures and results
- `data/` — Input datasets, when applicable

## Data Note

The coral colony measurements used in the introductory examples are illustrative practice data, not field observations.
